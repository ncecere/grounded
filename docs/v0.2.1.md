# v0.2.1: navigation and clarity

Status: **released as v0.2.1** (2026-09-29), after v0.2.1-rc.1 ran on the reference install. Branch `release/v0.2.1`. The owner's decisions are in §6.

v0.2.0 added evaluations, costs and budgets, OCR and SSO groups. The review before its release ([`ui-review/v0.2-review.md`](ui-review/v0.2-review.md)) found the product not cluttered overall, but the new features piled up in four places: the admin sidebar, the money pages, the evaluation screens, and phones. The must-fixes and quick wins shipped in v0.2.0; the owner deferred the structural changes to this release so they get their own walkthrough. Roadmap items I1–I9, plus G20 and the parts of G19 they need.

**No new features.** Every change moves, merges, renames or explains something that exists. Old URLs keep working (redirects), and the API doesn't change except where noted (I3, I9).

---

## 1. Exit criteria

1. **Admin navigation fits a laptop screen** (1440x900) with every group collapsed except the current one, and the current item is always visible. No admin page is more than one click from the sidebar.
2. **An admin can see which optional features are on** from the Overview, and turn each on or off from one place.
3. **A team owner can answer "how are we doing?"** from the team Overview: latest evaluation scores and regressions, and (for owners and admins) this month's spend against the budget.
4. **Spend and limits are separate:** Team settings shows spend in one compact strip; limits keep their own section.
5. **The agent editor has 6 tabs**, and the evaluation screens have a short breadcrumb and a 0–100% score chart.
6. **Chat and evaluations agree on verification:** each claim (sentence) has one verdict, shown with its text, and the evaluation "supported claims" share counts the same units.
7. The usual gates: redirects for every moved page (tested), the authorization matrix for any new operation, tests and E2E with axe, lint limits, CI green, and a walkthrough by role before the release.

Old URLs (`/admin/profile-migrations`, `/admin/legal-holds`) redirect to the new tabs. ⌘K keeps both names as keywords.

### I2 Admin Overview "Features" card

A card listing each optional feature with its state and a link to where it's configured: Evaluations, Cost tracking (Off / Track only / Enforce), OCR (backend), SSO groups (rule count), SystemOne, Public access, Maintenance. The **evaluations switch moves here** from Admin → Limits → Evaluations (which keeps only the two numeric limits). "Platform at a glance" moves above "Recent changes", which shows 5 entries.

### I3 Team Overview "Quality & spend", and a team Evaluations page

- **Team Overview** gains a "Quality & spend" row: each evaluation set's latest score with its trend and any regression, linking to the set; for owners and admins, this month's spend with the budget bar.
- **`/teams/:team/evaluations`** (today a 404, although it's the parent of every set's URL) becomes a list of all the team's sets: target KB or agent, latest score, trend, last run. It's the target of ⌘K "evaluations", of the Overview row, and of a new team sidebar item **Evaluations** (editors and above; members don't see it).
- API: the Overview row can use the existing set list (it already carries the latest run); no new operation expected.

### I4 Usage & spend

- Team settings' tab becomes **Usage & spend** when cost tracking is on (Usage & limits when off). Spend shrinks to a one-line strip ("$0.24 of $1.20 this month · 19% · resets Oct 1") with a meter; the by-agent and by-model tables go into a "Spend breakdown" disclosure.
- Each agent's **Analytics** tab shows its spend this month next to "Tokens by model".
- **Crawl domains moves to Data sources** as a tab (Sources · Crawl domains), so Team settings has 5 tabs: Members · Usage & spend · API keys · Audit log · General.

### I5 Costs Overview consolidated

KPI cards, the daily chart with "Show data" (the table behind a disclosure), and one **Top spenders** card with Teams · Agents · Models and one CSV button. About 1,100 px instead of 2,300.

### I6 Agent editor to 6 tabs

Versions moves out of the tab strip into the header's version badge ("v4 live" opens a menu: Version history, Compare, Revert), with the history as a record page. Tabs: **Build · Evaluations · Appearance · Share · Analytics · Settings**.

### I7 Admin team page

Cost tracking and the budget become a card on the admin team's **Overview**; its Limits tab ("Budget & limits" in v0.2.0) holds only limits again. The Budgets table's "Change budget…" keeps opening the dialog in place.

### I8 Analytics "Checks" tab

The eight SystemOne cards (citation checks, scope check) move to a **Checks** tab, shown only when SystemOne is configured. Overview keeps 14 cards and the chart moves up.

### I9 Per-claim verification

v0.2.0 gives each citation marker its own verdict and flags uncited factual sentences. v0.2.1 finishes the model:
- A **claim** is one factual sentence of the answer; it has one verdict: supported (by which sources), not supported, or uncited.
- The citation popover shows the claim's text, the verdict and the passage; the answer's summary counts claims ("9 of 10 claims supported").
- Evaluations' "supported claims" uses the same units, so a result page and the same answer in chat always agree.
- Stored additively in the message's citations JSON; the OpenAI-compatible API adds `claims[]` next to `citations[]` (additive).

### Small items

- **G20:** evaluation run links read "Retrieval , Sep 28…" (stray space).
- **G19 (the parts needed here):** a fixed 0–100% axis on the evaluation score chart (bitop-ui LineChart), and a collapsed breadcrumb item with a menu of the hidden crumbs.
