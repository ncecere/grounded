Limits of this evidence:

- The round-trip counts are for one agent with one knowledge base, no reranking, no SystemOne and no MCP tools. Other
  configurations make more; the reduction applies to the steps they share.
- No latency was measured end to end. Fewer round trips and parallel search shorten the wait by an amount that
  depends on the network between the API and Postgres and on the embedding call's duration.
- The chat rendering change is covered by a render-count test and a test that a citation chip keeps its DOM node
  across tokens, not by a browser profile.

## Behaviour changes that tests cover

- **Character sets.** `TestHTMLIsReadInItsDeclaredCharset` parses the same page in five encodings. Without the fix
  it fails for windows-1251, ISO-8859-2 and Shift_JIS.
- **Usage ledger.** `TestInsertUsageMatchesSingleRows` compares the multi-row insert with the single-row one, row for
  row, and checks that a row without metadata is still refused.
- **Migration 00069.** `TestMigration00069IndexesTheDeletePaths` checks the six indexes exist and are valid, takes
  the migration down and up, and checks the planner uses the index for a deleted session's lookup.
- **Request cache.** `internal/requestcache` is covered by unit tests: one load per request, none remembered after a
  failure, and no caching without a cache in the context. It is started only for a chat answer, a public chat request
  and a search. Permissions on passage text are not cached: they are checked on every read.
- **Parallel API tests.** Tests that replace process-wide state (the span recorder, `http.DefaultTransport`) or read
  an exact value of a process-wide counter are marked `serial`. With `-race` on 4 CPUs and a 3-connection pool the
  package passed twice in a row locally before the change merged.

Not covered by a test: the gateway transport's effect on a real HTTP/1.1 gateway (a unit test checks the clients
share one transport with 32 idle connections per host), and the 15-second freshness beyond what the unit and e2e
suites exercise. The unit suite found one page that needed a fresh read on open (the migration preflight); three more
were set by inspection.
