Limits of this evidence:

- The counter measurements are for one team with one source; per-source contention was spread over 16 slots and not
  measured beyond 12 concurrent workers. The triggers' cost on a single large `UPDATE` of documents could not be
  separated from the machine's noise (100k rows: 38 to 45 s with the triggers, 22 to 42 s without).
- The round-trip counts are for one agent with one knowledge base, no reranking, no SystemOne and no MCP tools (the
  MCP rows aside). The time-to-first-token figures use an artificial delay, not a real network.
- No connector exists, so the connector framework is covered by the API, worker and web tests with a test connector,
  not by a provider. The first connector (#259) adds an end-to-end test (#280).

## Behaviour changes that tests cover

- **Counters** (`internal/doccounts`): exact across upload, replace, every status change, the personal-data flag, tags,
  deleting a document, a re-crawl's unseen pages, a source and a team, platform-shared sources, and 12 workers
  ingesting while reconciles run; the backfill (migrate down to 71, write documents without the triggers, migrate up);
  repairing counters corrupted by hand; the daily job's warning; `grounded doctor`'s trigger check.
- **Passage reuse** (`internal/ingest`, `internal/httpapi`): an unchanged passage keeps its row and is not embedded;
  search results are the same; a changed title, prefix, model or input limit embeds the whole document; contextual
  chunks embed everything.
- **Retries** (`internal/ingest`): the parse record is reused only for the same version and content; OCR is not called
  or counted again; a partly scanned PDF retried for OCR is parsed again.
- **Retention** (`internal/retention`): a failed object-storage delete leaves the record and is retried on the next
  run.
- **Concurrent pre-flight** (`internal/agents`, `internal/parallel`): when several steps fail, the error is the one the
  serial order would have returned; a chat slot taken by a failing question is released; no step is left running
  (with `-race`).
- **Settings cache** (`internal/ttlcache`): a value is never served past its TTL, a failed load is never remembered, and
  a load that began before an invalidation doesn't store its result. Moderation is not cached.
- **MCP** (`internal/mcpserver`, `internal/mcpclient`): a knowledge base whose access is removed and an agent deleted
  between `tools/list` and `tools/call` are refused; a session the server ended is replaced and the call sent once more;
  every new connection goes through the address check.
- **Web** (`web/`): the streaming answer survives a background refetch (fails without the fix); the team query keys
  (fails without the fix); the conversation list's render count; the full Playwright suite (64 tests).
- **Text shortening**: a multi-byte test fails on the old byte-cutting copies.
- **Flaky tests (#281)**: a new `internal/gaps` test holds the topics job's lock from another connection (fails without
  the fix); the preview test with a pool of 2 failed at CI's line after 1,021 s and passes in about 3 s.
