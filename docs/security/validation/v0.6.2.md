## Upgrade rehearsal — passed

The repository's `make upgrade-test` ran locally with the published v0.6.1 image
as `OLD_IMAGE` and the exact new `grounded` digest above as `NEW_IMAGE`, on its own
Docker network, Postgres 17, Valkey and blob volume. It verified the old image's
fixture writes; new migration with the old process still running; old and new
reads (source, conversation, retrieval, API key); a new-image chat; then old-image
reads again. Both use **schema 53**. Containers, network and volume were removed.
This is candidate evidence; the required main/CI upgrade run remains a gate.
