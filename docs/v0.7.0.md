## Decisions

### Configuration as code

- **How it's applied (option A):** in the UI and through the API. A team's Settings gets **Export configuration** (YAML) and **Import configuration**, which shows a dry-run diff ("2 agents changed, 1 source added") before applying; the same export, dry run and apply are API endpoints a pipeline can call with an API key.
- **What's in a file:** names, settings, instructions, agent versions and references (a source's URL or crawl rules, a knowledge base's sources, webhooks). Never uploaded files, passages, conversations or secrets: keys stay in the target install and are referred to by name.
- **CLI and SDKs (owner):** a command-line tool may come back later (it would call the same endpoints); **no SDKs**.
