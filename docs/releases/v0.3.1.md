# Grounded v0.3.1

A small release after [v0.3.0](v0.3.0.md): no new settings and no database migrations. The full list is in the [changelog](../../CHANGELOG.md).

## Changes

- **Grounded has a logo:** a citation's brackets around a check (the "Cited" mark), for an answer backed by a source with its claim verified. It replaces the placeholder tile in the sidebar and on the sign-in page, and the favicon (SVG, `favicon.ico` and an Apple touch icon). An instance logo (`UI_LOGO_URL`) still takes its place.
- **Answers that arrive whole are shown from their start.** An answer checked by moderation before it's shown (the default for public agents) arrives all at once; the chat followed the bottom, so a long answer landed with its last lines in view. Now its question moves to the top of the view and the answer starts right below it. Streamed answers still follow as they're written, and scrolling back to the bottom resumes following.
- The README lists what each release added and what's planned next.

## Upgrading from v0.3.0

A rolling upgrade with no migrations. Change every `?ref=v0.3.0` in your overlay to `?ref=v0.3.1` and pin the new digests of `ghcr.io/ncecere/grounded` and, if you run OCR, `ghcr.io/ncecere/grounded-ocr`.

Verifying the images is as for [v0.2.0](v0.2.0.md#verifying-the-images), with the tag `v0.3.1`.
