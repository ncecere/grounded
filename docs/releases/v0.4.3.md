# Grounded v0.4.3

v0.4.3 is a security patch for v0.4.2. Grounded is now built with Go 1.26.9 and golang.org/x/net v0.60.0, which fix 13 advisories in Go's standard library and in x/net. Nothing else about the product changes.

## Highlights

- **13 Go advisories fixed** (GO-2026-6599, 6600, 6603, 6604, 6605, 6607 to 6613 and 6617). They cover HTTP/2 server memory and CPU exhaustion and a crash, HTTP/1 connection desynchronisation after a `CONNECT`, unbounded `Range` and MIME header parsing, `html/template` context tracking and `crypto/tls`. `govulncheck`, which runs on every push, flagged them against Go 1.26.7 and x/net v0.59.0, so all are treated as applying to Grounded; we haven't assessed each one's exposure in a typical deployment, and the patch makes that unnecessary. All are fixed in Go 1.26.9; five (6603, 6610, 6611, 6612 and 6617) also affect `golang.org/x/net` and are fixed in v0.60.0. GO-2026-6604 affects Windows only. With both updates `govulncheck` reports no vulnerabilities.
- Nothing else: no new pages, settings or API behaviour. The one other change since v0.4.2 is wording in the API reference (the `thinking` chat status event).

## Requirements

Unchanged from [v0.2.0](v0.2.0.md#requirements).

## Upgrading from v0.4.2

A rolling upgrade with no downtime. Take a backup as for any upgrade ([`operations/upgrades.md`](../operations/upgrades.md)), then change every `?ref=v0.4.2` in your overlay to `?ref=v0.4.3` and pin the new digests of `ghcr.io/ncecere/grounded` and, if you run OCR, `ghcr.io/ncecere/grounded-ocr`.

**No migrations** (the schema stays at version 44) and **no new environment variables**. There is nothing to configure and nothing people will notice.
