# v0.4.2: ready for a wider beta

Status: **being built** (owner, 2026-10-04). A patch release that fixes everything a pre-beta bug hunt found in [v0.4.1](releases/v0.4.1.md), before a larger beta.

## Scope (owner, 2026-10-04)

Four testers used v0.4.1 by role on a copy of the reference data (platform admin and auditor; a team owner and editor building an assistant; members, signed-out visitors, phones and keyboard; a visual sweep of every page at five widths) and filed 119 findings; the owner added two. After merging duplicates: 0 P0, 9 P1, 24 P2, about 70 P3. **All of them are in v0.4.2** (owner: nothing has been widely released yet). axe found no violations on any page tested.

The findings, with steps and screenshots, were kept with the test run; each is summarised in the milestone that fixes it below, under its tester ID (AD admin, BU builder, US users, VI visual, OW owner).

## Owner decisions

- **Scope:** every finding, P1 to P3 (2026-10-04).
- **OW-2, a Reranking page (option A):** reranking gets its own page, **Admin → Models → Reranking**, always in the sidebar like SystemOne: its status (on/off, model and health, candidates, time limit, agents that turned it off), a setup guide when nothing is set up (a connection that serves `/rerank` → a model of kind Rerank → choose it, with a button for each step and which are done), the settings (moved here from the Models page's dialog), a test with a sample query, and "Reranking: off · Set up" / "on · <model>" in Admin → Overview → Features. Before, its settings appeared only as a notice on Admin → Models once a rerank model existed, so nothing said reranking existed.

## As built: M3 (team pages)

- **BU-04 (P1):** the documents table's selection follows what it shows. A filter, a search or another page clears the selection it hides (the simplest consistent choice: nothing selected is ever out of sight), and a row that leaves the view on a refresh is dropped from it. The bulk bar, the footer and the Delete dialog count the same rows, and Delete deletes exactly the rows it names (disabled with none). Bulk Retry says why it's disabled. Vitest and an e2e (`web/e2e/documents-v042.e2e.ts`).
- **BU-08:** the web preview's failure to read the start page is a 422 `fetch_failed` (was 502) that says what the site answered: "That page returned 404 (not found). Check the address." (403, 429, 5xx, redirects and unreachable or slow sites too); the alert is titled "Couldn't preview pages". OpenAPI: `mapSite` no longer lists 502.
- **BU-11:** the documents list refreshes when the source's counts change, so a document retried from the Failed view comes back there when it fails again.
- **BU-12:** the upload dialog guards only a running upload; tags alone don't make Done ask "Leave without saving?".
- **BU-14:** fusion weight sliders move in hundredths (Page Up/Down by 0.1) and round to two decimals, so 0.02 shows and can be chosen again.
- **BU-16:** Team settings → General says "You can view these settings. Only platform admins can change them." to owners; the repeated-blocks rule names its unit ("5 pages or 20%"); the save bar counts invalid fields on source and knowledge base settings ("fix the 4 highlighted fields"). Left to M2/M5: the Enable agent dialog, widget origin chips ("Added tag", bitop-ui TagInput) and Share → Links (agent pages).
- **BU-17:** deleting a team source that knowledge bases search opens "… can't be deleted yet" naming them (links to their Sources tab), with no Delete button. Shared sources keep the server's 409 message.
- **BU-18:** a new API key's Expires on is the calendar DatePicker (named once, past days disabled, choose the day again to clear): Chrome names a native date input's segments twice ("Month Month") whatever the label, so no label fixes it.
- **BU-20:** Compare names runs to the second with their score, version, reranking and results per search; the expected-documents picker leaves out failed and skipped documents (no search finds them); the knowledge base Overview keeps Attach source as its primary, and empty states no longer repeat it. Left to M2/M1: the Agents list's version date, the widget panel items.
- **VI-10:** a web page without a title of its own is named after its decoded URL ("pig", not "doc%2Fcodewalk%2Fpig"; `internal/ingest`). Titles stored before are decoded for display, as are the paths under them (only text without spaces holding %XX escapes).
- **VI-11:** a repeated block found but removed nowhere (it's all those pages have, so the guard keeps it) reads "1 repeated block found, kept: it's the only text on the pages that have it."
- **VI-12:** tabs don't open with a second page header: on Crawl domains, Request a domain is the Data sources header's primary (as New data source is on Sources); API keys, evaluation sets (knowledge base and agent), questions and runs are titled cards like Members. The evaluation sets empty state no longer repeats New set (also VI-07 for the agent tab, which uses this component), nor Sources' New data source.
- **VI-13:** the knowledge base's "Used by agents" card shows the count once with the agents' names under it, and Documents ready has a caption.
- **VI-14, VI-14b:** the team Overview waits for its cards' data (a skeleton until then) and Home shows its conversations and teams once the agents are in, so nothing is pushed down as data arrives (CLS 0.10 → 0.0002 and 0 in a local build); a once-ready latch keeps a 404 query (cost tracking off) from looping. Overview cards in a row stretch to the same height and every count card has a caption.
- **VI-20:** read-only notices are one untitled info alert, "Members can view knowledge bases. Editors, admins and owners can change them." (`pages/team/access.tsx`): data sources, knowledge bases, Members ("Admins and owners can add, change and remove them"). Left to M2: the agent editor's notice ("Only editors, admins and owners can configure agents."), and to M5: the SettingsPage template's "Read-only" title.
- **VI-20b:** a member opening Evaluations, an evaluation set or Gaps sees "Only editors, admins and owners can see evaluations." (or gaps) instead of "Page not found" / "Not found".
