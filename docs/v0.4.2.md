# v0.4.2: ready for a wider beta

Status: **being built** (owner, 2026-10-04). A patch release that fixes everything a pre-beta bug hunt found in [v0.4.1](releases/v0.4.1.md), before a larger beta.

## Scope (owner, 2026-10-04)

Four testers used v0.4.1 by role on a copy of the reference data (platform admin and auditor; a team owner and editor building an assistant; members, signed-out visitors, phones and keyboard; a visual sweep of every page at five widths) and filed 119 findings; the owner added two. After merging duplicates: 0 P0, 9 P1, 24 P2, about 70 P3. **All of them are in v0.4.2** (owner: nothing has been widely released yet). axe found no violations on any page tested.

The findings, with steps and screenshots, were kept with the test run; each is summarised in the milestone that fixes it below, under its tester ID (AD admin, BU builder, US users, VI visual, OW owner).

## Owner decisions

- **Scope:** every finding, P1 to P3 (2026-10-04).
- **OW-2, a Reranking page (option A):** reranking gets its own page, **Admin → Models → Reranking**, always in the sidebar like SystemOne: its status (on/off, model and health, candidates, time limit, agents that turned it off), a setup guide when nothing is set up (a connection that serves `/rerank` → a model of kind Rerank → choose it, with a button for each step and which are done), the settings (moved here from the Models page's dialog), a test with a sample query, and "Reranking: off · Set up" / "on · <model>" in Admin → Overview → Features. Before, its settings appeared only as a notice on Admin → Models once a rerank model existed, so nothing said reranking existed.

## As built: M4

Admin portal and the Reranking page (branch `v042-m4`). No migration. API (additive): `GET /v1/admin/features`, `DELETE /v1/admin/teams/{team}/budget/extensions/{extensionId}`.

- **OW-2:** Admin → Models → Reranking (`/admin/reranking`, always in the sidebar and ⌘K): status (model and health, candidates, time limit, the published agents that turn it off), a 3-step setup guide with a button per step (Add model returns to the page), the settings moved from the Models dialog, and a before/after test; Overview → Features says "Off · Set up" or "On · <model>". Auditors read it. Docs `operations/rerank.md`; e2e for the setup path.
